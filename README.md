# パタパタ時計 v7（2026-11-24）

Rakuten Mini（横向き・Android 9 の Chrome）向けのフリップクロック。ライブラリ・画像なし（アイコンを除く）。

公開先：https://artschool0202.github.io/flipclock/（GitHub リポジトリ artschool0202/flipclock）

## v7 で変えたこと（v6 から）

- 25分・55分のお知らせから「ピンポン」をなくし、パタパタの音と動きだけにした（ベルを押したときの試し鳴らしもパタパタ）
- ポモドーロ終了のチャイムはそのまま

## v6 で変えたこと（v5 から）

- お知らせの時刻を 25分・50分 → **25分・55分** に変更
- パタパタを少しゆっくりにして（7回・約1.7秒）、いつものめくりに近い見た目にした

## v5 で変えたこと（v4 から）

- **毎時25分・55分のお知らせ**：4桁がバラバラの数字で「パタパタパタパタ」と素早くめくれ（約1.4秒）、正しい時刻で止まってから「ピンポン」を3回鳴らす
  - 右上にベルのアイコンを追加。既定はON、設定は次回も引き継ぐ。押すと試しにチャイムが鳴る
  - ブラウザの決まりで、**起動してから画面に一度触れるまで音は出ない**（動きは出る）
  - 22時〜6時は音を鳴らさず、動きだけ。ポモドーロ中はお知らせしない
- **雨のお知らせ**：1時間以内に雨の予報があると、数字とコロンが青くなる（ブラック・オレンジは明るい青、クリームは紺）
  - 判定：今降っている／15分ごとの降水量の予報で 0.1mm 以上／1時間ごとの予報で 0.1mm 以上か雨・雪の天気、のどれか
  - 降水確率だけでは青くしない（調布の予報で、雨量0なのに降水確率98%の時間があったため）
  - 長押しの画面の右下に「1時間以内に雨の予報」と降水確率を出す
  - 日本の15分ごとの予報は、1時間ごとの予報から補間した推定値
- URL の末尾に `#demo` を付けて開くと、青い色とパタパタを試せる

## v4 で変えたこと（v3 から）

- 長押しの全画面表示に、天気・気温・風速（m/s）を戻した
  - 1行目：日付と曜日／2行目：天気と気温／3行目：風速と秒／右下：取得地点と更新時刻
  - 長い天気名（「晴れ時々曇り」など）は、その行だけ文字を小さくして画面に収める
  - 表示時間は5秒から8秒に延長
- 天気は Open-Meteo（調布付近 北緯35.652・東経139.541、APIキー不要）から15分ごとに取得。失敗時は3分後に再試行し、最後に取れた値を出し続ける

## 普段の画面と操作（v3 と同じ）

- 普段は「HH:MM」の4桁だけ。数字は画面いっぱい
- 右上のアイコンは触ってから5秒で消える
- 22時〜6時は画面全体を薄暗くする。焼き付き防止に3分ごとに表示を最大6pxずらす

| 操作 | 動き |
| --- | --- |
| タップ | 通常時計 ⇄ 25分ポモドーロ（終了時は点滅＋振動＋効果音ONならチャイム） |
| ダブルタップ | テーマ切替：ブラック → クリーム → オレンジ |
| 長押し | 日付・天気・気温・風速・秒を全画面に表示（8秒。タップで閉じる） |
| 右上 □ | 全画面のオン／オフ |
| 右上 目 | 画面消灯防止（Wake Lock）。設定は次回も引き継ぐ |
| 右上 ベル | 毎時25分・55分のお知らせのオン／オフ（v5） |
| 右上 スピーカー | パタパタ音のオン／オフ（起動時はいつもOFF） |

## ファイル

| ファイル | 中身 |
| --- | --- |
| index.html | 画面の骨組み |
| style.css | デザイン・3テーマ・フリップの動き（CSS 3D） |
| app.js | 時計、ポモドーロ、長押し表示、天気、夜間減光、焼き付き防止、効果音、全画面、Wake Lock |
| manifest.json | ホーム画面に追加したとき、横向きの全画面で開く設定 |
| sw.js | オフラインでも開けるようにする。直したら CACHE 名の版を上げる（今は flipclock-v7） |
| icon.svg / icon-192.png / icon-512.png | ホーム画面のアイコン |

## 更新のしかた

GitHub の flipclock で「＋」→「Upload files」に、変えたファイルをドラッグして「Commit changes」。
端末では時計を一度閉じて開き直すと新しい版に切り替わる。
