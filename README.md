# パタパタ時計 v1（2026-11-24）

Rakuten Mini（横向き・Android 9 の Chrome）向けのフリップクロック。ライブラリ・画像なし（アイコンを除く）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| index.html | 画面の骨組み |
| style.css | デザイン・3テーマ・フリップの動き（CSS 3D） |
| app.js | 時計、ポモドーロ、効果音、天気、全画面、Wake Lock |
| manifest.json | ホーム画面に追加したとき、横向きの全画面で開く設定 |
| sw.js | オフラインでも開けるようにする（天気はキャッシュしない） |
| icon.svg / icon-192.png / icon-512.png | ホーム画面のアイコン |

## スマホに入れる手順

1. フォルダの中身を **HTTPS のサイト** に置く（GitHub Pages、Netlify Drop、Cloudflare Pages など。どれも無料）
   - `file://` で開くと、全画面・Wake Lock・ホーム画面アプリ化が動かない
2. Rakuten Mini の Chrome で URL を開き、メニュー →「ホーム画面に追加」（または「アプリをインストール」）
3. ホーム画面のアイコンから開くと、横向き全画面で起動する
   - Chrome は最新版に更新しておく（Wake Lock は Chrome 84 以降）

## 操作

| 操作 | 動き |
| --- | --- |
| 画面をタップ | 通常時計 ⇄ 25分ポモドーロ（終了時は点滅＋振動＋効果音ONならチャイム） |
| 画面をダブルタップ | テーマ切替：ブラック → クリーム → オレンジ |
| 右上 □ | 全画面のオン／オフ |
| 右上 目 | 画面消灯防止（Wake Lock）。設定は次回も引き継ぐ |
| 右上 スピーカー | パタパタ音のオン／オフ（起動時はいつもOFF） |

- 天気：Open-Meteo（調布付近 北緯35.652・東経139.541）。15分ごとに更新、失敗時は3分後に再試行
- タイマー中は右下に現在時刻を小さく表示
